# Capturas de pantalla

Las imágenes están **pendientes de capturar** en un equipo con MySQL 8.0 en
ejecución y un intérprete de Python con `tkinter` disponible. El entorno de
preparación de esta entrega no dispone de esos componentes, por lo que no se
pudo iniciar la interfaz ni el `.exe` para tomar las imágenes.

Esta lista queda como guía para completar el evidenciario sin modificar el
código:

| Archivo sugerido | Pantalla | Pasos |
|---|---|---|
| `01_login_crear_cuenta.png` | Login con enlace «Crear cuenta...» | Abrir la app antes de iniciar sesión |
| `02_padre_solicitar_vacante.png` | Formulario corto de vacante | Entrar como `padre_demo` → «Solicitar vacante» |
| `03_padre_mis_solicitudes.png` | Bandeja del padre con estados | Entrar como `padre_demo` → «Mis solicitudes» |
| `04_secretaria_vacantes_atender.png` | Bandeja filtrada en `Vacante` y aviso de >7 días | Entrar como `secretaria` → «Vacantes por atender» |
| `05_revision_vacante.png` | Alumno nuevo/anterior, última matrícula y cupos | Abrir `SOL-2027-0002` desde la bandeja |
| `06_contacto_registrado.png` | Observaciones y «Registrar contacto» | Registrar una llamada en la revisión |
| `07_matricula_paso1_bloqueado.png` | Asistente con nivel/grado precargados | Abrir `SOL-2027-0004` → «Completar matrícula» |
| `08_aprobacion.png` | Solicitud en carpeta `aprobadas/` | Aprobar `SOL-2027-0005` como secretaria |

Al capturar, verificar que no aparezca logo ni nombre de la institución, y que
los datos sean los ficticios incluidos en `datos_demo/solicitudes/`.
