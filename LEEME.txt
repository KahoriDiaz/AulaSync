AULASYNC — ENTREGA 5
====================
Aplicativo de escritorio (Python + tkinter, sin frameworks) para que la
secretaria registre matrículas en MySQL. Solo para secretarias.

Requisitos
----------
1. Windows 10/11. No hay que instalar nada: ni Python ni MySQL.
2. Descomprimir el ZIP en una carpeta con permiso de escritura (por ejemplo,
   Escritorio o Descargas), no dentro de "Archivos de programa".

Cómo abrir
----------
1. Descomprimir Entrega5_GrupoXX.zip.
2. Abrir AulaSync.lnk (o AulaSync\AulaSync.exe).
3. AulaSync enciende su propio MySQL 8.0 portátil (carpeta AulaSync\mysql, solo
   accesible desde la misma PC, puerto 3307) y abre directo el login. La primera
   vez copia la base con los datos de prueba (unos 15 segundos).
4. Al cerrar AulaSync, el MySQL portátil se apaga.
5. Para volver a los datos de prueba originales: cerrar AulaSync y borrar la
   carpeta AulaSync\mysql_data.

El OCR viene listo: la carpeta tesseract/ trae el ejecutable portable y el
idioma español. El OCR solo prellena; todo se puede escribir a mano.

Con un MySQL 8.0 propio (opcional)
----------------------------------
Si se borra la carpeta AulaSync\mysql, AulaSync usa un MySQL instalado y abre el
asistente de conexión: pide el usuario administrador (root) y su clave, crea
bd_matricula, el usuario matricula_app (solo SELECT y EXECUTE) y ejecuta los
scripts 01 a 06. La clave del administrador NUNCA se guarda.

Menú
----
Inicio | Mantenimiento | Realizar matrícula | Consultas | Ayuda
- Realizar matrícula: 1) documentos con OCR, 2) datos del estudiante, padre,
  madre, responsable y constancia, 3) verificación del código virtual en
  https://constancia.minedu.gob.pe/, 4) guardar datos, 5) registrar matrícula.
- Mantenimiento: CRUD de todas las tablas mediante procedimientos almacenados.
- Consultas: 10 reportes (exportan a Excel, PDF y CSV), distribución por
  secciones, listas y comparación, y panel de relaciones.

Aviso sobre antivirus
---------------------
PyInstaller puede provocar falsos positivos en Windows Defender. Si aparece una
alerta, agregar la carpeta a exclusiones. El código fuente está incluido.

Estructura del ZIP
------------------
Entrega5_GrupoXX.zip
├─ AulaSync/        (AulaSync.exe + dependencias + sql/ + tesseract/ + mysql/ portátil)
├─ AulaSync.lnk     (acceso directo con ruta relativa)
├─ codigo_fuente/   (proyecto sin .venv, .git, cachés ni config.ini)
├─ script_bd/       (los .sql 01 a 06, idénticos a sql/)
└─ LEEME.txt

Regenerar el entregable (desarrollo)
------------------------------------
Requiere MySQL Server 8.0 instalado en la PC de desarrollo (de ahí se copia el
MySQL portátil; otra carpeta se indica con la variable MYSQL_HOME).
1. pip install -r requirements.txt
2. .\build.bat        -> dist\AulaSync\AulaSync.exe + mysql\ + mysql_plantilla\
3. .\empaquetar.bat   -> Entrega5_GrupoXX.zip y AulaSync.lnk

Pruebas: python -m pytest   (sin MySQL se omiten las pruebas de base de datos)
