REGISTRO DE MATRÍCULA — ENTREGA 5
=================================

Requisitos para el revisor
--------------------------
1. MySQL 8.0 instalado y en ejecución. El ejecutable NO incluye MySQL.
2. Windows 10/11. No necesita instalar Python ni dependencias para ejecutar el .exe.
3. Opcional: Tesseract con idioma español (spa) para el autocompletado OCR.
   Si no está, los datos se ingresan manualmente.

Ejecución del entregable
------------------------
1. Descomprimir Entrega5_GrupoXX.zip (renombrar XX con el número de grupo).
2. Entrar en la carpeta MatriculaApp/ y ejecutar MatriculaApp.exe.
3. Si no existe config.ini, se abre el asistente de conexión:
   a) Probar la conexión con el usuario administrador de MySQL.
   b) Presionar "Crear base de datos y cargar datos de prueba".
      Esto crea bd_matricula, el usuario matricula_app y carga los scripts 01 a 06.
4. La clave del administrador de MySQL se pide de forma transitoria y NUNCA se guarda.
   Junto al .exe se crea config.ini con el usuario matricula_app / clave matricula_app.
5. Ingresar con los usuarios demo:

   Usuario        Clave             Rol
   -------------------------------------------
   secretaria     secretaria123     Secretaria
   padre_demo     padre123          Padre

6. Desde la cuenta secretaria revisar: Mantenimiento, Distribución, Listas y
   comparación, Reportes (10 consultas, 6 con JOIN, exportación Excel/PDF/CSV)
   y la Bandeja de solicitudes. Desde padre_demo, "Mis solicitudes".

Archivos junto al ejecutable (fuera del .exe)
---------------------------------------------
MatriculaApp/
├─ MatriculaApp.exe
├─ _internal/                 (dependencias; NO editar)
├─ sql/                       (scripts 01 a 06 usados por el asistente)
├─ tesseract/                 (opcional: tesseract.exe + tessdata/spa.traineddata)
├─ config.ini.example         (plantilla; copiar como config.ini si hace falta)
├─ config.ini                 (se crea solo; NO distribuir con claves reales)
├─ data/solicitudes/          (pendientes/, aprobadas/, rechazadas/)
└─ LEEME.txt

Estructura del ZIP
------------------
Entrega5_GrupoXX.zip
├─ MatriculaApp/     (exe + dependencias + sql/ + tesseract/ opcional)
├─ codigo_fuente/    (todo el proyecto documentado)
├─ script_bd/        (los .sql 01 a 06)
├─ documentos/       (informe, memoria descriptiva, manual de usuario)
└─ LEEME.txt

Aviso sobre antivirus
---------------------
PyInstaller puede provocar falsos positivos en Windows Defender u otros antivirus.
Si aparece una alerta, verificar la firma del archivo o agregar la carpeta a
exclusiones antes de ejecutar. El código fuente está incluido para su revisión.

OCR opcional
------------
Si la carpeta tesseract/ incluye tesseract.exe y tessdata/spa.traineddata, la
aplicación la detecta automáticamente. También se puede configurar en config.ini:

[app]
tesseract_cmd = C:\Ruta\a\tesseract.exe

Sin Tesseract, el botón de OCR se desactiva y los campos se llenan manualmente.

Regenerar el entregable (desarrollo)
------------------------------------
1. pip install -r requirements.txt
2. build.bat        -> dist\MatriculaApp\MatriculaApp.exe
3. empaquetar.bat   -> Entrega5_GrupoXX.zip

En PowerShell los .bat de la carpeta actual se invocan con ./ delante:
  .\build.bat
  .\empaquetar.bat
No hace falta tener pyinstaller.exe en el PATH: build.bat usa python -m PyInstaller.
