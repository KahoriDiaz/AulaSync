AULASYNC — ENTREGA 5
====================

Requisitos para el revisor
--------------------------
1. MySQL 8.0 instalado y en ejecución. El ejecutable NO incluye MySQL.
2. Windows 10/11. No necesita instalar Python ni dependencias para ejecutar el .exe.
3. El OCR viene listo para usar: la carpeta tesseract/ incluye el ejecutable
   portable y el idioma español (spa). No hay que instalar Tesseract por separado.
   Si algo falla, la app muestra un diagnóstico y permite pegar el texto leído
   en otra herramienta.

Ejecución del entregable
------------------------
1. Descomprimir Entrega5_GrupoXX.zip (renombrar XX con el número de grupo).
2. Entrar en la carpeta AulaSync/ y ejecutar AulaSync.exe.
3. Si no existe config.ini, se abre el asistente de conexión:
   a) Probar la conexión con el usuario administrador de MySQL.
   b) Presionar "Crear base de datos y cargar datos de prueba".
      Esto crea bd_matricula, el usuario matricula_app y carga los scripts 01 a 06.
4. La clave del administrador de MySQL se pide de forma transitoria y NUNCA se guarda.
   Junto al .exe se crea config.ini con el usuario matricula_app / clave matricula_app.
5. Ingresar con los usuarios demo de secretaria:

   Usuario        Clave             Rol
   -------------------------------------------
   secretaria     secretaria123     Secretaria
   secretaria2    secretaria123     Secretaria

6. Desde la cuenta secretaria revisar: Mantenimiento, Distribución, Listas y
   comparación, Reportes (10 consultas, 6 con JOIN, exportación Excel/PDF/CSV),
   "Panel de relaciones" (indicadores y ficha 360° de cada matrícula),
   "Bandeja de solicitudes" y "Vacantes por atender". Al revisar una solicitud,
   el semáforo valida DNI, duplicados, grado, cupo, documentos y responsable;
   sugiere la sección con más vacantes y avisa si el alumno ya está registrado.

Flujo en dos etapas (nuevo)
---------------------------
1. El padre solicita una vacante con un formulario corto: contacto, hijos
   (máximo 6 hermanos) y nivel/grado deseado. La disponibilidad es referencial:
   se puede enviar aunque diga "Sin vacantes".
2. La secretaria revisa la vacante: distingue alumno nuevo de anterior, ve la
   última matrícula, el grado sugerido y las vacantes por sección (30 menos
   matriculados). Puede copiar el contacto, registrar la llamada, observar o
   rechazar. Las solicitudes sin respuesta por más de 7 días aparecen resaltadas.
3. Al aceptar la vacante solo cambia el JSON y se agrega la observación con los
   documentos a presentar. No se reserva cupo ni se escribe en MySQL.
4. Recién entonces el padre ve "Completar matrícula": se abre el asistente de
   5 pasos con nivel y grado precargados y bloqueados, y el envío queda como
   "Enviada" en la etapa Matrícula.
5. La aprobación de la secretaria ejecuta una única transacción en MySQL y
   mueve la carpeta a aprobadas/.

Los estados son: Borrador → Enviada → Vacante aceptada → Enviada →
(Observada ↔ Enviada) → Aprobada. Rechazada es posible desde cualquier etapa.
Los detalles y las decisiones de diseño están en
documentos/DISENO_FLUJO.md (incluido en el ZIP).

Archivos junto al ejecutable (fuera del .exe)
---------------------------------------------
AulaSync/
├─ AulaSync.exe
├─ _internal/                 (dependencias; NO editar)
├─ sql/                       (scripts 01 a 06 usados por el asistente)
├─ tesseract/                 (tesseract.exe + tessdata/spa.traineddata + licencia)
├─ config.ini.example         (plantilla; copiar como config.ini si hace falta)
├─ config.ini                 (se crea solo; NO distribuir con claves reales)
├─ data/solicitudes/          (pendientes/, aprobadas/, rechazadas/ con ejemplos)
├─ data/perfiles/             (perfiles de cuentas creadas desde el login)
└─ LEEME.txt

Estructura del ZIP
------------------
Entrega5_GrupoXX.zip
├─ AulaSync/     (exe + dependencias + sql/ + tesseract/ listo para usar)
├─ codigo_fuente/    (todo el proyecto documentado, incluye datos_demo/)
├─ script_bd/        (los .sql 01 a 06)
├─ documentos/       (informe, memoria, manual, diseño del flujo y capturas)
└─ LEEME.txt

Datos demo incluidos
--------------------
Se distribuyen 9 solicitudes ficticias en datos_demo/solicitudes/ y build.bat
las copia dentro de AulaSync/data/solicitudes/. Cubren Borrador, Enviada,
Observada, Vacante aceptada, Aprobada y Rechazada en ambas etapas. Los DNI son
ficticios y el padre de la mayoría de los ejemplos es padre_demo (29481029).
Antes de comprimir, empaquetar.ps1 elimina config.ini y los perfiles *.json, y
reemplaza data/solicitudes por los ejemplos para no distribuir datos reales.
Capturas pendientes: se enumeran en documentos/CAPTURAS.md.

Aviso sobre antivirus
---------------------
PyInstaller puede provocar falsos positivos en Windows Defender u otros antivirus.
Si aparece una alerta, verificar la firma del archivo o agregar la carpeta a
exclusiones antes de ejecutar. El código fuente está incluido para su revisión.

OCR listo para usar
-------------------
El ZIP incluye tesseract.exe y tessdata/spa.traineddata, así que el botón
"Autocompletar con OCR" funciona sin instalar nada. Si se quiere usar otro
Tesseract, se indica en config.ini:

[app]
tesseract_cmd = C:\Ruta\a\tesseract.exe

En el paso 4 del asistente hay tres controles:
- "Autocompletar con OCR": lee una imagen y muestra los campos para confirmar.
- "Pegar texto OCR": usa el texto reconocido en otra herramienta (fallback).
- "Probar OCR": diagnostica ejecutable, idioma, librerías y hace una prueba real.
Si falta algo, el aviso dice exactamente qué componente hace falta y ofrece el
fallback de texto pegado; el formulario nunca queda bloqueado.

Regenerar el entregable (desarrollo)
------------------------------------
1. pip install -r requirements.txt
2. build.bat        -> dist\AulaSync\AulaSync.exe
3. empaquetar.bat   -> Entrega5_GrupoXX.zip

En PowerShell los .bat de la carpeta actual se invocan con ./ delante:
  .\build.bat
  .\empaquetar.bat
No hace falta tener pyinstaller.exe en el PATH: build.bat usa python -m PyInstaller.

Pruebas (desarrollo, sin MySQL):
python -m unittest tests.test_fase_a tests.test_fase_b tests.test_fase_d
python -m unittest tests.test_fase4 tests.test_fase5 tests.test_fase6 tests.test_fase7 tests.test_fase_e tests.test_interfaz tests.test_ocr tests.test_automatizacion

Con MySQL 8.0 cargado se pueden ejecutar además:
python -m unittest tests.test_sql tests.test_integracion_db
